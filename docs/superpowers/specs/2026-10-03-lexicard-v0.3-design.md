# Lexicard v0.3: one English card with a picture

Status: draft for review · 2026-10-03 · builds on v0.2 (`feat/v0.2`, not yet merged)

## 1. Why

The owner reviewed v0.2 and wants a simpler card:

> "No me gusta que tenga múltiple lado de inglés y español. Yo solo quiero ver la tarjeta de Anki en inglés, y que nomás me diga la traducción y cómo crear oraciones, y el IPA y cómo se dice, y si se puede una imagen. Muy importante la imagen."
>
> "Tiene que ser verbos más cotidianos, no tanto del libro."

Decisions made with the owner (2026-10-03):

| Question | Decision |
|---|---|
| Card types | **One card per word**, English on the front. No Spanish→English card. |
| Image source | **Cloudflare Workers AI, free tier** (FLUX.1 [schnell]). |
| Image placement | **On the back**, so it doesn't give the meaning away. |
| Extras on the back | Book sentence, trap warnings (only when real), short English definition. |
| Existing reverse cards | **Delete** the 5 existing Spanish→English cards. |
| Examples and picture | **Everyday life** with common verbs, not the book's scene. |

Gemini's free tier allows 0 images a day on every image model (checked against the owner's key: `limit: 0` on `gemini-3.1-flash-lite-image`, `gemini-2.5-flash-image` and `gemini-3.1-flash-image`), which is why images come from Cloudflare.

## 2. The card

One note type, **Lexicard**, with one card (template name kept as `Recognize`).

**Front**

```
            give up                 ← headword
     /ˌɡɪv ˈʌp/ · phrasal verb      ← IPA · part of speech
              ▶ (audio)             ← plays automatically
```

**Back** (front stays on top, then the answer)

```
      ┌──────────────────────┐
      │       PICTURE        │      ← everyday scene showing the meaning
      └──────────────────────┘
         dejar / abandonar          ← Spanish, big
  to stop doing something that you did regularly   ← short English definition

  HOW TO USE IT
   give up + something   I gave up coffee a month ago.
   give up + -ing        She gave up smoking last year.

  ⚠ Falso amigo: ✗ «actualmente» → ✓ «en realidad»   ← only when there's a real trap

  From your book: “…she finally gave it up.” · Example Book — Author   ← small, last
```

Register (informal, slang…) shows next to the part of speech when it isn't neutral. The picture is centered, rounded, and at most 45% of the screen height so the text stays visible on a phone.

### Fields (v3)

`Headword, IPA, POS, Register, Spanish, Definition, Usage, Image, Audio, Warning, Context, Book`

- **Usage**: HTML built by Lexicard from 2–3 `{pattern, example}` pairs (escaped, the expression in `<b>`).
- **Image**: filled by AnkiConnect (`<img src="lexicard-give_up-1791000000.jpg">`).
- Fields from v2 that the new card doesn't use (`Pattern, Example, Cloze, Collocations, PronTip, ContextOpen, CEFR`) stay in existing note types. Removing fields deletes data, so Lexicard never does it, and new installs simply don't create them.

## 3. What Gemini writes (schema v3)

Key order (kept by writing the schema by hand, as in v2):

`status, expression_in_text, headword, pos, sense, ipa, register, definition, spanish, trap, warning, usage, image_scene`

- **usage**: 2–3 items `{"pattern": "give up + -ing", "example": "She <b>gave up</b> smoking last year."}`. Each pattern is a short, reusable frame (with "something", "someone", "+ -ing", "to + verb"). Each example has at most 12 words, is about **everyday life** (home, work, food, friends, shopping, travel, health), uses common verbs and simple words, and has the expression in `<b></b>`. It never copies the book's sentence, scene or characters.
- **image_scene**: one English sentence, at most 25 words, describing a concrete **everyday** scene that shows the meaning used in the book. Family-friendly: for violent or sensitive words, a mild, symbolic scene. No objects with writing (signs, books, screens, labels).
- **Removed** from v2: `pattern` (single), `example`, `collocations`, `sound`, `pron_tip`. Pronunciation tips go away. The owner asked for IPA and audio only.
- **Kept**: sense selection from the book sentence, the trap/warning rules and lists (false friends, prepositions, calques, confusables, register), the Mexican-Spanish rules, `status` for names and non-English words.

The book sentence is used only to pick the right sense. It reaches the card only as the small "From your book" line.

The five worked examples in the system prompt (give up, seek, actually, depend on, under the weather) are rewritten with `usage` and `image_scene` in everyday settings.

### Code checks (pure, after Gemini)

- `normalize`: the prompt asks for 2–3 usage items, while the code accepts 1–3 (at least one with a non-empty example, extras dropped). Items missing `<b>` get the expression bolded (`ensure_bold`). `image_scene` gets trimmed. If it's empty, no picture is requested.
- `quality_problem` (ask the fallback model once): the definition uses the headword; any usage example overlaps the book sentence by more than 50%; no usage example at all.
- Repairs kept from v2: warning validation and table fill-ins, Spanish de-duplication, look-alike and vulgar-word filtering. The pronunciation-tip repair is removed.
- IPA stays as in v2 (CMUdict first, Gemini only if plausible).

## 4. Pictures

**Provider:** Cloudflare Workers AI, model `@cf/black-forest-labs/flux-1-schnell`.

```
POST https://api.cloudflare.com/client/v4/accounts/{CLOUDFLARE_ACCOUNT_ID}/ai/run/@cf/black-forest-labs/flux-1-schnell
Authorization: Bearer {CLOUDFLARE_API_TOKEN}
{"prompt": "<scene>. <style>", "steps": 4}
→ {"result": {"image": "<base64 JPEG>"}, "success": true, ...}
```

- **Free allowance:** 10,000 neurons a day, and one image costs about 43–58 neurons, so roughly 170–230 images a day.
- **Prompt:** `image_scene` plus one fixed style suffix, so the whole deck looks consistent: *"Simple, friendly flat illustration, clean outlines, soft colors, plain light background, no text, no letters."*
- **When:** at **Save**, in the same KOReader subprocess as the audio (audio, then picture, then AnkiConnect). Nothing is drawn for cards that are cancelled.
- **How it reaches Anki:** the base64 JPEG goes to AnkiConnect `addNote` as `picture: [{data, filename: "lexicard-<slug>-<time>.jpg", fields: ["Image"]}]`. The Kindle never decodes it.
- **Failure never blocks the card.** If there are no credentials, `IMAGES=off`, an HTTP error, a timeout (15 s block / 30 s total) or a reply without an image, the card is saved without a picture. The success message then adds one line: *"No picture: daily limit reached / check the Cloudflare token / network error."*
- **Outbox:** a note that can't reach Anki is kept on the Kindle with its picture and audio inside (about 0.3–0.6 MB each).
- **Test connections** also checks the Cloudflare token (`GET /client/v4/user/tokens/verify`, which costs no neurons).

New `.env` keys (all optional; pictures are off without the first two):

| Key | Default |
|---|---|
| `CLOUDFLARE_ACCOUNT_ID` | — |
| `CLOUDFLARE_API_TOKEN` | — (a token with the **Workers AI** permission) |
| `IMAGES` | `on` |
| `IMAGE_MODEL` | `@cf/black-forest-labs/flux-1-schnell` |

`AUDIO=word+example` now reads the first usage example.

## 6. Moving existing decks to v0.3

**What the plugin does automatically** (first Save after upgrading), without deleting anything:

1. Add the missing v3 fields (`Usage`, `Image`).
2. Push the v3 `Recognize` templates and CSS (version mark `lexicard-notetype v3`).
3. If the note type still has a `Produce` template, wrap its front in `{{#Cloze}}…{{/Cloze}}`. v3 notes leave `Cloze` empty, so they get no reverse card. Reverse cards of older notes stay, so other users keep theirs.

**One-time upgrade for this deck** (`scripts/upgrade-v0.3.lua`, run on the Mac):

1. Remove the `Produce` template (`modelTemplateRemove`), which deletes the 5 Spanish→English cards (dark, leisurely, ruthlessness, drift, snowflake). The English cards and their review history stay. The owner approved this on 2026-10-03.
2. Backfill the 5 existing notes: rebuild each card from its headword and book sentence with the v3 pipeline, then update `Usage`, `Image`, `Definition`, `Spanish`, `IPA` and `Warning` (`updateNoteFields` plus a picture). Existing audio is kept.
3. Print a summary. Then **one full sync**: on the Mac, Sync → *Upload to AnkiWeb*; on the iPhone, *Download from AnkiWeb*. This single full sync also covers the pending v0.2 field changes.

## 7. Approaches considered

- **Image source:** Cloudflare FLUX.1 [schnell] (chosen: free, small JPEGs, a plain JSON API the Kindle can call). Alternatives were Gemini "Nano Banana 2 Lite" (best at following meaning, but $0.034 per image and needs billing) and free stock photos (no account, but off-target for verbs and abstract words). FLUX.2 [klein] 4B is newer and also cheap, but needs a multipart request; it can be tried later if schnell's pictures disappoint.
- **Where pictures are made:** on the Kindle at Save (chosen; same path as audio, no extra server). On the Mac through an Anki add-on would need the Mac on and a second code base. Before the preview would spend quota on cancelled cards, and e-ink can't show them well anyway.
- **Dropping the reverse card:** the plugin never deletes, and a one-time script deletes for this deck (chosen). Having the plugin remove `Produce` automatically would delete other users' cards without asking.

## 8. Testing

- **Unit specs (offline):**
  - Config: Cloudflare keys and `IMAGES`.
  - Prompt: schema v3 and examples.
  - Gemini: `normalize` and `quality_problem` with `usage` and `image_scene`.
  - Note: Usage HTML, escaping and bold, the `picture` parameter, preview text.
  - Note type: v3 fields, a single template, the conditional `Produce`.

  - main save flow: picture included, failure message.
  - Repair: pronunciation-tip code removed.
- **Prompt eval** (`scripts/eval-prompt.lua`, 19 cases): checks are updated for v3. Each case needs 2–3 usage items, examples of at most 12 words with the expression bold, no example overlapping the book by more than 50%, and no book names (capitalized words from the book sentence) in examples or `image_scene`. `image_scene` must be non-empty, at most 25 words, and free of quotes. Target: no regressions on the v2 checks that still apply.
- **Picture review:** generate pictures for 8 eval words (concrete noun, abstract noun, phrasal verb, idiom, adverb, a violent word from the book) with `scripts/try-card.lua --image`, and look at them before shipping.
- **On the Kindle:** hold a word, Save, and check on the iPhone: one card, picture on the back, audio, everyday examples.
