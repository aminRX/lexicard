# Lexicard v0.2: better cards — design spec

Date: 2026-10-03 · Status: approved · Builds on `2026-10-03-lexicard-design.md` (v0.1).

## 1. Why

v0.1 works end to end on the Kindle. Real use and the evaluation showed these problems:

- IPA for the inflected form instead of the headword (*realized*, *ran*), and occasional garbage (*/opak/*).
- Invented pronunciation tips (a "double t" in *reluctant*; «lé» for *leisurely*).
- Warnings that aren't Spanish-speaker traps, and a missed false friend (*realize ≠ realizar*) after the last prompt change.
- A wrong Spanish equivalent (*indispuesto* for *reluctant*) and vulgar slang for a neutral word.
- A one-word book sentence ("Leisurely.") shown twice on the front.
- CEFR levels that are often one level off.
- Robotic text-to-speech voices on the review device.

Three research reports (learner's dictionaries; card design for Spanish speakers; prompting plus Spanish-speaker error data) inform the changes below.

## 2. Principles

- **Gemini writes; code checks and repairs.** Anything a lookup does better (IPA, false friends) comes from data, not the model.
- **Still one tap per card.** No manual editing; checks run before the preview.
- **Earlier decisions stand:** two cards per word, Mexican Spanish, an English definition plus Spanish equivalents, Gemini audio.

## 3. Prompt v2

- **Shorter rules.** About six rules, phrased positively. Field limits move into the schema descriptions instead of being repeated in the prompt. (Small models drop rules as the list grows.)
- **Five worked examples** in `<example>` tags, each obeying every rule: a split phrasal verb (*gave it up*), an irregular form (*sought → seek*), a false friend (*actually*), a preposition trap (*depends on*), and an idiom (*once in a blue moon*). Today's examples break our own rules and the model copies those mistakes.
- **New fields that make the model reason first:**
  - `sense`: at most 12 plain words, the meaning in this sentence. Written before the definition; not shown on the card.
  - `trap` (before `warning`): `none`, `false_friend`, `preposition`, `calque`, `confusable` (two English words for one Spanish word, like *borrow/lend* → *prestar*), `register`.
  - `sound` (before `pron_tip`): `none`, `v_b`, `i_ɪ`, `vowels`, `schwa`, `s_cluster`, `ed`, `z`, `th`, `dʒ_j`, `ʃ_tʃ`, `h`, `cluster`, `stress`, `silent`.
- **Reference lists in the prompt:** about 25 false friends, 18 preposition and calque errors, and 14 sound traps for Spanish speakers.
- **Removed from the model's job:** `cefr` (unreliable), `context` and `surface` (built by code from what KOReader already knows).
- **Field rules:**
  - `definition`: at most 15 common words, dictionary style ("to …" for verbs), never the headword or its family.
  - `spanish`: Mexican usage, same meaning and register as the definition, never the Spanish look-alike of a false friend, no vulgar words unless the English is slang.
  - `warning`: Spanish, written as "✗ … → ✓ …".
  - `example`: at most 12 words, everyday, built differently from the book's sentence.
  - `ipa`: General American, of the headword (only used when the dictionary lacks the word).
- **Thinking:** the evaluation compares Flash-Lite's default against `thinkingLevel: "low"`; the better one ships.

## 4. Checks and repairs in code (after Gemini, before the preview)

| Field | Rule |
|---|---|
| Context | Built from the book sentence. Bold the model's `expression_in_text` if it appears, else the held word. If the sentence has fewer than 6 words, include the previous sentence. |
| IPA | From CMUdict, in Oxford American style (`ər`, `r`, no `ː`). Phrasal verbs get `ˌverb ˈparticle`. The model's IPA is used only for words CMUdict lacks, and only if it contains valid IPA symbols; otherwise the field stays empty. |
| Warning | Kept only if `trap` ≠ none and it passes a type check (a false friend names a similar Spanish word; a preposition trap quotes a preposition; a register warning needs a non-neutral register). If the headword is in the false-friend table and no warning came back, the table fills it in. |
| Pronunciation tip | Kept only if `sound` ≠ none, it doesn't talk about letters or spelling (except a silent letter the word really has), and any `/…/` it quotes appears in the IPA. |
| Spanish | Duplicates removed (ignoring case and accents); the English headword, the Spanish look-alike and blocklisted vulgar words are dropped, unless the register is slang. |
| Example | Exactly one bold span (repaired if missing); at most 15 words. |
| Definition and example | If the definition contains the headword, or the example copies more than half of the book sentence, retry once with the fallback model; if that fails, keep the first card. |

## 5. Cards

**Fields:** add `Audio` and `ContextOpen`. `Context` is now built by code. `CEFR` stays in the note type but is no longer filled or shown. `Cloze` gets first-letter hints.

**Recognize (English → meaning)**
- Front: the headword, its audio (plays automatically), and the book sentence behind a tap (`{{hint:Context}}`), shown directly when `ContextOpen` is set (phrasal verbs and idioms).
- Back: Spanish; definition; IPA · part of speech · pattern · register; ⚠ warning; 🗣 pronunciation tip; book title in small type. The example sentence moves to the Produce card, so the two cards use different sentences.

**Produce (Spanish → English)**
- Front: "Say it in English"; Spanish; definition; part of speech (plus register when it isn't neutral); the example with first-letter hints, one blank per word: *My dad g____ ____ smoking.*
- Back: the headword with audio; IPA · pattern; the full example; collocations; warning; pronunciation tip.

**Migration:** Lexicard adds missing fields to the existing "Lexicard" note type (`modelFieldAdd`), then pushes the new templates and CSS. Existing notes keep working.

## 6. Audio (Gemini voice)

- `gemini-3.8-flash-lite-tts`, voice "Kore", generated when you tap **Save**.
- The headword by default. `AUDIO=word|word+example|off` in `.env`.
- Stored as a WAV in Anki's media through `addNote`'s `audio` option. The base64 from Gemini passes straight to AnkiConnect, so the Kindle never decodes audio.
- 15-second timeout; if it fails, the card is saved without audio.
- Anki's `{{tts}}` device voices are removed from the templates.
- Size: about 64 KB per word (about 64 MB per 1,000 cards); about 5× more with the example.

## 7. Anki review order (one-time, with the user's OK)

Create an options preset "Lexicard" (a copy of the deck's current one) used only by *Reading vocabulary*: bury new, review and interday-learning siblings; show new cards by card type (Recognize first). Other decks are untouched. This keeps the two cards of a word off the same day and makes recall come after recognition.

## 8. Decisions (user, 2026-10-03)

- Book sentence on the Recognize front: **behind a tap**, shown automatically for phrasal verbs and idioms (`ContextOpen`).
- Review order: **yes**, create the "Lexicard" options preset for *Reading vocabulary* only.
- Spec approved; build it.

## 9. How we know it's better

- The evaluation grows from 12 to about 20 self-written cases, adding *sought*, *depends on*, *once in a blue moon*, *borrow/lend*, *sympathetic* and a one-word sentence.
- Automated checks score every card: headword in the definition, warning validity, pronunciation-tip validity, example overlap, IPA validity, duplicate Spanish.
- v0.1 and v0.2 scores are compared before deploying.

## 10. Not in v0.2

CEFR from word lists (licences unclear), a defining-vocabulary check (NGSL), images, typed answers.
